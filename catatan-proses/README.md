# Catatan Proses — Privia

**Versi lengkap dan resmi ada di satu berkas: `docs/catatan-proses.md`** — memuat
Minggu 1 sampai 16 dalam format **Lampiran C** (10 bagian per minggu: yang dikerjakan,
READ, BREAK, FIX, BUILD, tantangan wajib, penggunaan AI, biaya, daftar periksa, dan
yang macet). Itu berkas yang dipakai untuk pengumpulan mingguan `<NIM>-m<minggu>.zip`.

Folder ini berisi versi **per blok** dengan gaya penulisan berbeda (bagian
"Dikerjakan / Tidak dikerjakan / Yang saya pelajari"). Isinya berasal dari berkas yang
benar-benar ada di repo (`logs/`, `catatan-pemakaian.md`) dan dari apa yang benar-benar
dikerjakan — termasuk yang **belum** dikerjakan.

| Berkas | Cakupan |
|---|---|
| `minggu-01-03.md` | Blok A: persoalan, peta, model & biaya |
| `minggu-04-06.md` | Blok B: structured output, prompt v1 → v2, tool pertama |
| `minggu-07-09.md` | Blok C: grounding, chunking, ambang relevansi, baseline |
| `minggu-10-13.md` | Blok D: workflow vs agen, tool & state, guardrails |
| `minggu-14-16.md` | Blok E: set uji, evaluasi, risiko, refleksi |

Berkas pendukung Minggu 1: `docs/minggu-1-Ekstraktor-Privasi.md` (tabel READ dan empat
percobaan BREAK beserta jawaban analisis) dan `docs/minggu-1-pemetaan-persoalan.md`
(tiga calon persoalan dan tantangan wajib).

**Cara membaca:** kalau butuh format yang dinilai, buka `docs/catatan-proses.md`. Kalau
butuh cerita proses yang lebih panjang per blok, buka berkas di folder ini.
